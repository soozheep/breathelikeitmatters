# Breathe Like It Matters — Sonic Remedy

**Audiosensory Resonance by Soozhee | Caelverum Music**

Live site: [breathelikeitmatters.vercel.app](https://breathelikeitmatters.vercel.app)

## Assets required

Upload the following from Google Drive folder `02 Breathe Like It Matters` into the `assets/` directory:

- `blim-cover.PNG` → `assets/blim-cover.PNG`
- `BREATHE LIKE IT MATTERS MASTERED.mp3` → `assets/BREATHE LIKE IT MATTERS MASTERED.mp3`
- Lyric cards: `blim-01.png` … `blim-12.png` → `assets/lyrics/`
- Teaching cards: `blim-card-01.png` … `blim-card-04.png` → `assets/cards/`

Then redeploy on Vercel (or push to trigger).

## Structure

Matches the professional luxe Sonic Remedy style of pouritout.vercel.app and the clarity series sites: sticky header with hamburger on mobile, cover + custom MP3 player, shareable lyric cards, 4 teaching cards, streaming links, full social share support.
